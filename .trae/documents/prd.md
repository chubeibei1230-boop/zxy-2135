## 1. 产品概述

企业内部服务申请管理平台，解决企业内部服务申请流程中字段配置不灵活、历史数据与配置变更不同步、审批反馈不透明等痛点。面向管理员、执行人和监督人三种角色，提供可配置字段的动态表单、字段版本快照、审批流转与处理反馈闭环。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 通过管理员接口登录 | 维护申请类型、配置字段（类型/必填/选项）、管理字段版本 |
| 执行人 | 通过执行人接口登录 | 填写申请表单、补充材料说明、查看自己申请的状态和退回原因 |
| 监督人 | 通过监督人接口登录 | 查看所有申请处理状态、退回原因、导出申请数据 |

### 2.2 功能模块

1. **登录与角色切换页**：角色选择与身份验证，按角色进入不同功能视图
2. **申请类型管理页**（管理员）：创建/编辑申请类型，配置字段列表
3. **字段配置页**（管理员）：为申请类型添加/编辑/删除字段，设置字段类型、是否必填、选项值
4. **申请提交页**（执行人）：根据申请类型的字段配置动态渲染表单，提交申请
5. **申请详情与补充页**（执行人）：查看已提交申请、补充材料说明、查看退回原因
6. **审批管理页**（监督人）：查看所有申请列表、审批通过/退回、填写退回原因
7. **数据导出页**（监督人）：按申请创建时的字段版本导出Excel/CSV

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 申请提交 | 申请类型选择 | 选择要提交的申请类型 |

## 3. 核心流程

**申请提交流程**：执行人选择申请类型 → 系统加载当前字段配置 → 执行人填写动态表单 → 提交时系统保存字段快照（版本化） → 申请进入待审批状态

**审批流程**：监督人查看待审批列表 → 打开申请详情（按字段快照渲染） → 通过/退回（退回需填写原因） → 执行人收到反馈 → 可补充材料后重新提交

**字段版本兼容流程**：管理员修改字段配置 → 仅影响新申请 → 已有申请保留创建时的字段快照 → 详情页和导出均按快照版本渲染

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1e3a5f) + 琥珀色强调(#d97706)
- 按钮风格：圆角(8px)，带轻微阴影，主操作按钮填充色，次要操作边框样式
- 字体：标题用 Noto Serif SC，正文用 Noto Sans SC
- 布局风格：单栏内容居中，上下分区，最大宽度960px
- 图标：lucide-react线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 角色选择卡片 | 三张角色卡片横排，图标+角色名+描述，hover提升阴影，点击进入 |
| 申请类型管理 | 类型列表 | 卡片网格布局，每张卡片含类型名+字段数+操作按钮 |
| 申请类型管理 | 字段配置区 | 表格式展示，每行含字段名+类型标签+必填标识+操作按钮 |
| 字段配置弹窗 | 表单 | 模态弹窗，含字段名输入、类型下拉、必填开关、选项编辑区 |
| 申请提交 | 动态表单 | 上下排列的表单控件，文本输入框/数字输入/日期选择/单选按钮组/复选框组/文本域 |
| 申请详情 | 快照表单 | 只读表单展示，标签-值对排列，退回原因高亮警示 |
| 审批管理 | 申请列表 | 表格布局，状态标签着色，行点击展开详情 |
| 数据导出 | 筛选+操作 | 筛选条件区+导出按钮，进度提示 |

### 4.3 响应式设计

- 桌面优先设计，最大内容宽度960px居中
- 平板适配：卡片网格从3列变2列
- 移动端适配：单列布局，表格变为卡片列表

### 4.4 设计理念

采用"工业实用主义"风格：结构清晰、信息密度适中、操作路径短。表单区域使用浅灰底色区分，操作按钮固定在可视区域底部。状态标识使用色彩编码（待审批-琥珀、已通过-翠绿、已退回-朱红）。字段类型使用小型标签胶囊区分。
